01 / WHAT'S INSIDE

报告里有什么

  • 参考重复度：整篇和分段两个维度，不只看总数字。
  • 风险段落：用颜色标出高风险和需注意的句子。
  • 来源提示：标出可能相似的公开文本类型，方便核对。
  • 改写方向：给语序、论证角度和句子重心的调整建议。
02 / HOW TO READ

怎么读

  • 先看高风险：这些段落优先处理，不要整篇平均用力。
  • 再看需注意：保留观点，换表达和句序，别只换同义词。
  • 核对引用：引用、数据、术语要保留原意，不能一起改掉。
  • 最后复检：改完再上传，看风险段落有没有下降。
03 / BOUNDARY

边界

  • 不是官方查重：站内报告只做参考，不替代知网 / 维普 / 万方。
  • 不承诺包过：检测结果受学校系统、提交版本和时间影响。
  • 不伪造数据：只优化表达，不编造研究结果和参考文献。
  • 文件不留存：浏览器端解析，不上传到本站服务器。

为什么我的报告和学校结果不一样？

对比库、算法、提交版本和时间都可能不同。站内报告只用于定位高风险段落，最终以学校检测为准。

报告会保存我的论文吗？

免费初检在浏览器里解析，不上传到本站服务器。整篇订单的文件通过邮箱沟通，交付完成后按约定处理。

高风险就一定要全改吗？

不一定。先判断是不是引用、术语或数据；引用要保留出处，表达重复才需要改写。

改写后会再给报告吗？

整篇订单会按约定复检；免费初检只覆盖前 1,200 字，不包含无限次复检。
