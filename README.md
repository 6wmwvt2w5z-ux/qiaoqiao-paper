## 页面结构

- `index.html`：首页，免费初检入口、查重报告示例、四业务轮播、价格表、流程、付款与 FAQ
- `paper.html`：论文降重 / 润色，含上传初检、报价、AI 初改
- `ppt.html`：PPT 制作，按页报价
- `word.html`：Word 格式排版，按字数报价
- `excel.html`：Excel 表格，按表报价
- `report.html`：查重报告示例，含总览 / 逐句 / 改写三个视图和边界说明
- `pricing.html`：完整价格表与报价规则
- `faq.html`：按论文、报告、文档服务、付款与隐私分类的常见问题
- `about.html`：品牌定位、做什么 / 不做什么、交付承诺和联系方式
- `site.css` / `site.js`：所有页面共用的样式和交互（轮播、报价、报告 tabs、邮件下单）

## 技术说明

多页静态站，由 GitHub Pages 从 `main` 分支根目录发布。论文页的 `.docx` 在浏览器端用 JSZip 解析；AI 初改调用第三方免费接口，接口繁忙时使用本地规则保底。新页面共用 `site.css` 与 `site.js`，不依赖后端。
